# G25 Admixer

A standalone web application for genetic ancestry modeling using Global25 (G25) coordinates.

## Features

- Ancestry admixture modeling
- Synthetic population creation
- Population averaging and weighted averages
- Coordinate similarity comparisons

## Usage

Open the HTML file in your web browser.
